# Portafolio personal

**Demo:** https://luisch57.github.io

## Tecnologías
- HTML semántico
- CSS (variables, Flexbox, Grid y media queries)
- Git y GitHub Pages

## Qué aprendí
- Separar el contenido (HTML) de la presentación (CSS).
- Crear un diseño responsive que funciona en celular y en computadora.
- Versionar un proyecto con Git y publicarlo gratis con GitHub Pages.

## Cómo verlo en tu computadora
1. Descarga o clona este repositorio.
2. Abre `index.html` con la extensión Live Server de VS Code.
